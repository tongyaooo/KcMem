01 · Product Position

为什么 Agent 需要记忆服务？

WHY MEMORY

重要信息跨会话留存

  • 上下文有边界：单次对话和模型上下文有限，跨会话后，偏好、项目背景和已确认事实不一定还在。
  • 重复说明影响体验：没有长期记忆，用户可能反复补充背景，Agent 也可能重复提问，任务不易连续推进。
  • 需要可持续的信息层：把值得保留的内容从一次性对话中沉淀下来，供后续任务按需调用。
WHAT MEMORY ENABLES

让交互更个性化，任务更能接续

  • 记住长期信息：沉淀用户偏好、关键事实、项目约定和阶段进展。
  • 按需找回：后续请求按用户及问题检索相关记忆，只把有用信息补充给 Agent。
  • 延续服务体验：减少重复沟通，让回答更贴合用户，让跨会话任务更顺畅。
02 · Use Cases

典型应用场景

01

长期陪伴与个性化助手

场景解释：持续沉淀用户偏好、身份特征和交互习惯，在后续会话中提供更贴合个人的回应。
举例：记住用户偏好简洁回答，之后优先用简明方式解释问题。

02

工作与研发辅助 Agent

场景解释：保存编程偏好、项目约定、常用工具和已确认的排障经验，辅助跨会话接续工作。
举例：记住用户常用 Python、pytest 和类型标注，在后续代码任务中按这些习惯给出建议。

03

多角色数字员工

场景解释：不同数字员工可按岗位和业务任务关注不同信息维度，并在适用场景中调用相关记忆。
举例：客服 Agent 关注产品与问题处理历史，研发 Agent 关注技术栈和项目约定。

04 · Memory Layers

记忆分层

  1. L1
    富文本记忆

    将对话信息格式化，同时保留对话原文。

  2. L2
    原子事实

    将零散表达抽取为可检索、可更新的事实片段。

  3. L3
    会话摘要

    将会话内容压缩为一段摘要，为记忆提取提供更丰富的上下文。

  4. L4
    身份画像

    抽取用户特质、人设画像、长期偏好和与 Agent 的交流方式，支持跨会话、跨 Agent 复用。

  5. L5
    记忆摘要

    将同一归属者跨会话的多个话题聚类归并为场景摘要，呈现用户在一段时间内某类事务的整体面貌；支持按天级、全局级聚合，并维护版本以供历史回溯。

01 · INPUT提交对话按用户、Agent 和会话标识提交对话或文本。
02 · L1原文同步保存格式化并保留原文，作为即时记忆基础。
03 · L2–L4提取事实与画像L2 可同步或异步；会话摘要和用户画像异步生成。
04 · L5话题聚类与场景归并会话内形成 MemBox，跨会话归并为 MemScene，并生成场景摘要。
05 · SEARCH融合检索用户过滤后进行关键词与向量检索，RRF 融合结果供 Agent 使用。
时序信息：提取时结合绝对时间和相对时间生成时间戳，并向事实、会话摘要和画像层传递。检索可返回秒级时间戳，由 LLM 结合查询生成时序结果；用户画像可定期或手动更新，并在更新时处理冲突、保留最新记录。
05 · Product Features

产品能力特征

01 · COMPATIBILITY

Mem0 兼容接入

通过服务地址、API Key 与 Mem0 SDK 或 HTTP 调用接入。

  • 连通性检查与鉴权
  • 写入、列表、读取和语义搜索接口
  • 无需应用自行托管抽取模型和 Embedding
02 · EXTRACTION

中文与时序记忆提取

针对中文输入和带时间的事件信息进行优化。

  • 支持中文分词器
  • 结合绝对时间、相对时间处理时序信息
03 · MEMORY LAYERS

多层记忆组织

覆盖原文、事实、摘要和身份画像等不同粒度。

  • 同步与异步写入形态
  • 异步任务独立重试与断点恢复机制
  • 支持按需组合不同层级信息
04 · RETRIEVAL

关键词与向量检索融合

结合关键词检索与 Embedding 向量检索，召回用户范围内的相关记忆。

  • 通过 RRF 融合两路检索结果
  • 返回候选记忆与相关度分数
  • 向量检索支持 Cosine / L2 距离方式
05 · EXTRACTION STRATEGIES

灵活的记忆提取策略

面向不同业务场景，支持预置与自定义等多种提取方式，灵活确定记忆提取重点。

  • 支持预置策略，方便快速接入
  • 支持用户自定义提取策略
  • 可按 Agent 角色、业务场景调整关注维度
06 · SCENE & SHARED MEMORY

场景摘要与共享记忆

跨会话聚合多个话题形成 MemScene 场景摘要，并围绕不同 Agent 角色与业务场景组织记忆，支持相关任务复用。

  • 会话内按话题聚类形成 MemBox
  • 跨会话归并为 MemScene 并生成摘要，支持按天级、全局级聚合与版本回溯
  • 面向不同数字员工、场景与层级提取关注点，促进可复用信息在相关 Agent 间共享

07 · HOW TO CONNECT

接入方法

01 · API / SDK

自有应用接入

  • 客户端：使用 MemoryClient，或通过 httpx / curl 调用。
  • 连通与鉴权：GET /v1/ping/ 自检；请求头使用 Authorization: Token <API_KEY>。
  • 写入：POST /v3/memories/add/，user_id 放请求体顶层；返回 PENDING 表示异步受理。
  • 验证：轮询 POST /v3/memories/；filters 放 JSON body，分页参数放 query。文档示例约 2–4 秒，需以查询结果确认落库。
  • 检索与管理：POST /v3/memories/search/ 做语义检索；单条记忆可通过 /v1/memories/{id}/ 读取、更新、删除。删除后也需查询确认。
02 · OPENCLAW

插件接入

  • 安装 KSC Mem0 插件。
  • 配置 apiKey、baseUrl 和 userId，然后重启 Gateway。
  • 也可在星流 OpenClaw 部署时选择记忆服务。
03 · CONSOLE

控制台配置与管理

  • 创建实例，配置 VPC 和安全组。
  • 生产业务优先使用内网访问。
  • 配置提取策略，并使用控制台检索记忆、查看记忆概览和实例监控。
